# M1.5-08 — Housekeeping: dead fields, stale types and docs

**Milestone:** M1.5 · **Size:** S · **Depends on:** — · **Status:** ✅ Done
**Written against:** commit `e9f5b8c` (2026-10-10)

## Summary

A batch of small, low-risk cleanups that should land before M2 so the execution-model work starts
from a truthful codebase. Each is independently verifiable and none should change behaviour.

## Why now

- A stale type or a doc that contradicts the code costs every future agent (and human) real time.
  M0-02 removed the macro DSL; leftovers from it are still typed and documented as if alive.

## In scope

1. **Dead struct fields.** `TinyCI.Step` still defines `mode: :inherit` and `requires: []`
   (`lib/tiny_ci/tiny_ci.ex`), neither of which is read anywhere (only `Stage.mode` is used).
   Remove both and any construction sites.
2. **Stale type.** `TinyCI.Stage.when_condition` is typed `(map() -> boolean())` but holds a quoted
   AST. Correct the `@type` to the actual representation (consult `DSL.ConditionEval`).
3. **Stale docs.** `docs/reliability.md:39` says "M0-06 is still pending" while it is ✅ and
   implemented; fix the sentence and trim the resolved boundary bullets (M1.5-05/07 remove more).
   Also update `TinyCI.Action.Metadata`'s "advisory until T8" wording — T8 landed and the sandbox
   reads it.
4. **Dead compatibility shim.** `lib/tiny_ci/sandbox/redaction.ex` is a 5-line `@deprecated`
   forwarder to `TinyCI.Redaction`. No `lib/` code references it; its only reference is its own
   test, `test/tiny_ci/sandbox/redaction_test.exs`. Delete both together.

## Out of scope

- Any behavioural change to the executor, DSL, or events.
- Renaming or moving modules other than deleting the confirmed-dead ones above.
- The output renderer consolidation (that is M1.5-07).
- Local `erl_crash.dump` files and the `tiny_ci_lsp/tiny_ci_lsp` escript: they are not tracked and
  are already ignored (`.gitignore:17`, `tiny_ci_lsp/.gitignore:6,8`). Nothing to do in the repo.

## Read first

- `lib/tiny_ci/tiny_ci.ex` — the `Step`/`Stage` structs and types.
- `lib/tiny_ci/sandbox/redaction.ex`, `test/tiny_ci/sandbox/redaction_test.exs`, and
  `grep -rn "Sandbox.Redaction" lib test`.

## Docs
